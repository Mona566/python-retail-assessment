Data path

Read → prepare → analyse → store/export → package/email. Excel COM and Outlook stay single-threaded.

Read

Locate workbook · SHA-256 · single ExcelFile + per-sheet read_excel (no re-open). Required UCI columns validated per sheet.

↓

Prepare

Cross-sheet dedupe · enrich taxonomy (return line / confirmed / adjustment) · vectorized business keys & helpers · schema gate.

↓

Analyse

Shared non-cancellation sales view · product/country/month/returns/customer/timing · IQR anomaly quotas · Summary narrative.

↓

Store

Parquet clean ledger · ThreadPool for independent audit JSON/CSV writes · xlsxwriter base book · native PivotTables + PNG.

↓

Output

Validation (prep / analyses / workbook / PNGs) · full ZIP + email-safe ZIP · Outlook dry-run HTML; send only with explicit flags.

Architecture

main.py only orchestrates. Business logic lives in focused src/ modules with a single metrics contract.

main.py

CLI · PipelineRun state machine · stage exits · send policy

data_processing

Load · dedupe · enrich · parquet · parallel audit I/O

analysis_*

Rankings · anomalies · summary narrative

excel_*

xlsxwriter · pivots · PNG · specs as SSOT

validation

Prep / analyses / workbook / PNG contracts

packaging + email

Full vs email-safe ZIP · Outlook dry-run / one send

Design decisions

Why these shapes — not just what files exist.

Metrics contract (METRICS_VERSION) Gross / Net / return-line taxonomy / Top-N live in one module so Summary, Pivot, and email cannot drift. Meaning changes require a version bump.
Fail loud, don’t “almost ship” Blank PNGs, visible Grand Totals on rate pivots, stale --reuse-clean schema, invalid recipients → non-zero exit. No silent subset when Clean_Data exceeds Excel’s row limit.
Threads only for independent I/O Excel sheet parse and COM stay sequential. ThreadPoolExecutor overlaps parquet/CSV/JSON audit writes where sinks do not share mutable state.
Observability by default time.perf_counter() via PipelineRun.step / timed_phase; logs include duration and rows_per_sec; run JSON stores timing_summary + peak_rss_mb.

Known limits & next steps

  • macOS Excel + Outlook required for Pivot/PNG/send; unit tests mock those surfaces.
  • ~1M-row workbook often exceeds mailbox limits — email-safe ZIP omits xlsx on purpose.
  • Openpyxl load of the full UCI workbook remains the largest prep wall-clock; calamine/engine experiments are a follow-up.
