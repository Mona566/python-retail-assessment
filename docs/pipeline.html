Stages

0 — Start

parse_args · setup_logging · ensure_dirs. Logs under output/logs/.

Flags: --reuse-clean, --skip-excel / --skip-png / --skip-zip, --email-preview-only, --send / --send-to.

1 — Prepare

prepare_dataset() or load_prepared() in data_processing.py.

  • Locate workbook + SHA-256
  • Single ExcelFile load of both year sheets
  • Cross-sheet dedupe → enrich taxonomy → Parquet + audit JSON/CSV

Return taxonomy: is_return_line → is_confirmed_return (cuts Net) vs is_stock_adjustment (units only).

2 — Analyse

run_analyses(clean) → AnalysisBundle (summary, six tables, anomalies, narrative) → output/analysis_summary.json.

Product / Country (ex-UK) / Monthly / Returns Top-N / Customer / Timing · IQR anomaly quotas · contract KPIs.

3 — Excel + PNG

build_workbook: xlsxwriter base book → xlwings native PivotTables → six full-table PNGs. Rate/helper pivots must hide bottom Grand Total or the run fails.

4 — Validate

run_validations: row/metric consistency, UK exclusion, sheet/Pivot presence, non-empty PNGs. Failures → exit code 1.

5 — Package

Full submission ZIP (includes xlsx) + email-safe ZIP (no xlsx, mailbox-friendly).

6 — Email (dry-run by default)

HTML preview + CID MIME draft under output/email_preview/. Real Outlook send only with explicit --send; at most one message.

Suggested reading order

  1. src/metrics.py — number definitions

  3. src/data_processing.py — enrich / dedupe
  4. src/analysis*.py — rankings & anomalies
